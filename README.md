# ArchNet · Dictionary Extension

Extension methods for dictionaries: copy a dictionary without its empty values.

- Unity **6000.0** or newer · No dependency.
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/DictionaryExtension.git
```

## Use

```csharp
using ArchNet.Extension;

var filled = texts.WithoutEmptyValues();
```
